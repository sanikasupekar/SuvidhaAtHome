# Suvidha At Home

## About the Project

Suvidha At Home is a home service management application developed as a team project. It is designed to help customers book home services and track their booking status. The application includes separate modules for customers, service providers, and administrators.

## Features

- User Login
- Home Service Booking
- Booking Status Tracking
- Service Provider Module
- Admin Module
- Firebase Database Integration

## Technologies Used

- Java
- JavaFX
- Firebase Realtime Database

## Project Modules

### 1. Login Module

Provides the login functionality for accessing the application.

### 2. Service Booking Module

Allows customers to book home services.

### 3. Booking Tracking Module

Helps customers track their service booking status.

### 4. Service Provider Module

Supports service providers in managing service requests.

### 5. Admin Module

Provides functionality for managing application users and services.

## Database

Firebase Realtime Database is used for storing and retrieving application data.
